# Wallpaper Viewer

A simple desktop wallpaper viewer built with Python and Tkinter. Click "Next" to cycle through a collection of wallpaper images.

## Features

- Loads all images from a `wallpapers` folder automatically
- Click "Next" button to cycle through images
- Clean dark-themed GUI

## Tech Used

- Python 3
- Tkinter (GUI)
- Pillow (image handling)

## How to Run

```bash
pip install pillow
python wallpaper_viewer.py
```
